📘 Student Record Management System (C Language Project)
This is a beginner-level Student Record Management System written in C, built as a simple console-based application. It allows users to perform basic operations on student data such as:

🔧 Features:
✅ Add (Insert) new student records at any position

🗑️ Delete student records from a specific position

✏️ Update student name or roll number

📋 Display all student records

❌ Exit the program

🧠 Concepts Used:
Structures (struct)

Arrays

Loops and conditionals

Switch-case statements

Basic memory management without dynamic allocation

💻 How It Works:
Users are prompted to:

Enter the initial number of students and their data

Use a menu-driven interface to manage student records interactively

📌 Note:
The name field currently accepts single-word names (no spaces)

Input validation is basic—improvements are possible in future versions

📦 Future Improvements:
File handling to store data permanently
